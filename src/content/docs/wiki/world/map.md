主世界以「北岛」为核心，主城位于北岛南岸。传送大厅可以直达下列地点。

## 常用地点

| 地点 | 坐标 | 说明 |
| --- | --- | --- |
| 主城广场 | X 0 / Z 0 | 出生点、导览牌、公告板 |
| 玩家市场 | X 128 / Z -64 | 商店街，可申请摊位 |
| 资源世界门 | X -96 / Z 48 | 每两周刷新 |
| 活动场 | X 220 / Z 180 | 建筑赛、小游戏 |
| 公共农场 | X 64 / Z 96 | 小麦、胡萝卜、甘蔗 |

## 建家区域

主城外围保留公共空间，可从三个方向找地块：

- **北侧森林**：林地多，适合木构建筑，注意保留树木走廊
- **南侧平原**：地势平缓，适合城镇群，已有多处聚落
- **湖畔**：景观好，但需避开公共码头与航道

## 铁路与交通

- 环线铁道连接主城、市场与三个玩家聚落
- 干线铁路属于公共设施，改动前需公示
- 私人车站可以接入环线，接入点找铁道负责人确认
