需要留档的正式通知都发布在公告区，一条公告对应 `src/content/news/` 下的一个 Markdown 文件。

## 公告分类

| 分类 | 内容 |
| --- | --- |
| 版本 | 客户端版本、插件更新、兼容性说明 |
| 活动 | 周末活动、建筑赛、节日场 |
| 规则 | 规则修订与生效时间 |
| 维护 | 停机维护、备份、性能调整 |

## 查看全部公告

[→ 打开公告列表](/news/)

## 订阅方式

- 加入玩家群，公告会同步到群内
- 关注仓库的 Releases，重大更新会打标签
- RSS：`/rss.xml`（构建后可接入）
