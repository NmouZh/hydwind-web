## 核心循环

Hydwind 不做主线任务，也不强推进度。玩家进来后大致会经历三个阶段：

1. **落脚**：资源世界拿物资，主城外围选地块
2. **建家**：房子、农田、仓库，逐步接入公共设施
3. **参与**：加入组织、开店、参加活动，或只是安静挖矿

## 四类玩法

### 生存

原版难度，保留饥饿与死亡掉落（可在主城设置「新手保护」十分钟）。不加入数值插件，不做等级与装备强化。

### 建筑

服务器最看重的一块。主城、聚落、铁路、景观都来自玩家自建。没有风格审查，但有公共通道与高度限制的基本约定。

### 活动

- **周末活动**：小游戏、寻宝、PVP 擂台，通常两小时
- **季度建筑赛**：给定主题与地块，评分以完成度与创意为主
- **节日场**：春节、中秋的临时场景，活动后保留一部分做纪念

### 社区

玩家组织自治，服务器只提供名录与规则边界。城镇、公会、工作室都可以在[公开组织](/orgs/)登记。

## 服务器节奏

| 项目 | 设定 |
| --- | --- |
| 在线时段 | 全天，凌晨 4:00 自动备份 |
| 资源刷新 | 每两周周六 04:00 |
| 主世界 | 长期保留，不随周目重置 |
| 活动频率 | 每周一次小型，每季度一次大型 |
| 存档计划 | 每周全量备份，保留最近 8 份 |

## 不做什么

- 不卖资源、不卖权限、不卖数值优势
- 不做强制日常、不做签到奖励
- 不为了活跃度压缩生存节奏
