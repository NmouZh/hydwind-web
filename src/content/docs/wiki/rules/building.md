## 基本边界

- 不要拆除、移动或占用其他玩家**已经明确使用**的建筑和箱子。
- 公共道路、主城、活动场和传送点周围需要保留通行空间。
- 大型建筑、村民大厅、刷怪塔建议先和附近玩家沟通位置。

## 什么算「已经明确使用」

满足任意一条即可认为有主：

| 迹象 | 说明 |
| --- | --- |
| 有领地标记 | 木牌、栅栏、`/claim` 领地边界 |
| 有持续维护 | 近期有改动、有照明、有箱子分类 |
| 有公开登记 | 组织档案或群内说明过位置 |

一条都没有、且三个月无改动的建筑，可以报给管理员走「公示—清理」流程，**不要自行拆除**。

## 公共通道

主城到各聚落之间的主干道、铁路与传送点属于公共设施：

- 不得封堵、截断或以建筑遮挡
- 需要接入私人物业时，先与相邻玩家和管理员确认接入点
- 跨区域工程（干线铁路、跨海桥）需在群里公示方案

## 领地申请

1. 在主城导览牌处领取木锄
2. 圈选范围（建议不超过 128×128）
3. 执行 `/claim` 并命名
4. 用 `/claim list` 确认

领地只保护方块不被非成员破坏，不保护箱子上锁，储物请用 `/lock`。

## 误操作怎么办

立刻在群里说明位置与时间，管理员可回滚。主动说明通常不追责；隐瞒后被举报，按恶意处理。
