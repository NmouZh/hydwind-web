服务器对外免白名单，但第一次进服需要按下面的顺序做一遍，避免进服后被传送门或资源包卡住。

## 第一步：确认版本

- 客户端版本：**Minecraft Java 1.21.x**
- 客户端类型：官方启动器、HMCL、PCL 均可
- 不需要安装额外模组；服务器会下发一个轻量资源包（约 3 MB），允许后自动加载

:::caution[不要用整合包]
带 OptiFine 之外的光影整合包容易在进服时被踢出。如果反复掉线，先用纯净 1.21.x 客户端试一次。
:::

## 第二步：添加服务器

1. 打开「多人游戏」→「添加服务器」
2. 服务器地址填 `play.hydwind.com`
3. 名称随便填，例如 `Hydwind`
4. 双击进入

服务器开启了正版验证。离线账号（非正版）无法进入，这是为了避免冒名与破坏后无法追溯。

## 第三步：完成新手引导

第一次进服会出生在主城广场。广场四周有四块导览牌：

| 位置 | 内容 |
| --- | --- |
| 北侧 | 建家区域指引与领地申请方式 |
| 东侧 | 公共农场、公共熔炉与共享仓库 |
| 南侧 | 传送大厅：资源世界、活动场、玩家聚落 |
| 西侧 | 规则摘要与管理员联系方式 |

看完导览牌后，从南侧传送大厅进入资源世界拿第一批物资，再回主城外围选地块建家。

## 常见卡点

- **进服就掉线**：多为资源包下载超时，退出重进一次即可；仍失败请在群里反馈。
- **无法破坏方块**：主城广场与公共设施默认保护区，主城外围及以外区域可自由建设。
- **找不到自己家**：用 `/home set` 记录坐标，或用 `/back` 返回上一个传送点。
