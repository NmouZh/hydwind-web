## 版本与客户端

**Q：支持哪些版本？**
A：Java 版 1.21.x。跨版本连接（如 1.20 客户端）不稳定，建议对齐到服务器当前版本。

**Q：手机或基岩版能进吗？**
A：不能。服务器只开放 Java 版，没有基岩版互通。

**Q：需要装模组吗？**
A：不需要。服务器只下发资源包，用于自定义方块贴图与界面字体。

## 白名单与账号

**Q：要申请白名单吗？**
A：目前不需要，正版账号可直接进入。

**Q：离线账号为什么进不去？**
A：服务器开启正版验证。破坏行为需要可追溯，这是硬性要求。

## 建设与领地

**Q：怎么保护自己的建筑？**
A：主城外围地块可申请领地，用木锄圈选后执行 `/claim`。未申请领地的区域不提供回滚之外的保护。

**Q：可以拆别人的建筑吗？**
A：不可以，哪怕看起来已经废弃。长期无人使用的建筑由管理员统一公示后再处理。

**Q：能建红石机器吗？**
A：能，但高频、常开的机器必须加开关，并遵守[红石与机器](/wiki/rules/redstone/)的限制。

## 资源与世界

**Q：资源世界多久刷新？**
A：每两周周六凌晨刷新，刷新只影响资源世界，主世界建筑不受影响。

**Q：主世界会换周目吗？**
A：不会。主世界长期保留，只有大版本结构性更新时才会开新周目，并提前一个月公告。

**Q：能带走别人的箱子吗？**
A：公共仓库可以，玩家私有箱子不可以；拿错请放回并在群里说明。
