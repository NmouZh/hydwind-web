服务器的日常沟通集中在玩家群内。游戏内公告与群公告具备同等效力。

## 渠道

| 渠道 | 用途 | 备注 |
| --- | --- | --- |
| 玩家交流群 | 日常交流、组队、活动报名 | 群号见门户页脚或主城导览牌 |
| 游戏内公告 | 规则调整、维护通知 | 登录时会推送最近三条 |
| 本站公告 | 需要留档的正式通知 | [/news/](/news/) |
| GitHub Issues | 功能建议、文档纠错 | 适合能写清楚复现步骤的反馈 |

## 反馈的基本原则

1. **先沟通，再上报**：玩家之间的建设、交易纠纷，优先直接找对方谈。
2. **给位置和截图**：报破坏、报卡服时，附上坐标与时间，处理速度快很多。
3. **不要公开对线**：争议问题交给管理员，群内互相指责会先被禁言。

## 举报与申诉

- 破坏、偷窃、外挂：私聊管理员，附坐标、时间、截图。
- 误封申诉：在群内 @ 管理员，说明角色名与大致封禁时间。
- 处理原则见[规则总览](/wiki/rules/)的「处理方式」一节。
